HOW TO PLAY

長押しして、上下へ。

  1. 01
    曲を再生する

    再生ボタンでスタート。「曲を選ぶ」から収録曲を切り替えられます。

  2. 02
    パッドを長押し

    押している間だけエフェクトON。指を離すとOFF。2本の指で別々のエフェクトを重ねられます。

  3. 03
    そのまま上下に動かす

    音色や速さを変えられます。音符の表示は拍に同期し、上へ動かすほど細かく刻みます。強さは100%固定。指を離してもパラメータは残ります。

PC：A / S / D / J / K / L を押している間だけON。パッドにフォーカスして上下キーでも調整できます。

エフェクトの仕組み・参考仕様
しゃりしゃり / BitCrusher
サンプルを一定時間保持して、金属的な音に。上下で保持する長さを変えます。
エアー / Flanger
1ミリ秒前後の短い遅延を重ね、くし形フィルターの音に。上下で遅延時間を変えます。
こもる / Low-pass filter
高音をしぼるフィルター。上下でカットオフ周波数を変えます。
ぶつ切り / Gate
音が鳴る区間と無音の区間を交互に。上下で音符の細かさを選びます。
リピート / Retrigger
押した瞬間からの音を反復し、2拍ごとに取り込む音を更新します。
やまびこ / Echo
取り込んだ音を反復し、1回ごとに音量を60%へ。押し直すと新しい音になります。

KONAMI公式の操作説明と、K-Shoot MANIAの公開仕様を参考にした独自実装です。本家の音声処理そのものではありません。
